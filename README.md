# Портфель ДРСС

Учёт проектов и загрузки сотрудников Департамента развития и сопровождения систем.
React + Vite, без бэкенда: все данные хранятся в `localStorage` браузера пользователя.

## Разделы

- **Сотрудники** — список, добавление/удаление, должность, руководитель, формат работы (офис, гибрид с числом офисных дней, удалённо, совместитель, аутстафф), ставка (1 / 0,75 / 0,5 / 0,25), статус.
- **Проекты** — три вкладки:
  - *Утверждённые* с подвкладками *Сопровождение* и *Развитие*;
  - *Неутверждённые* (без финансирования, по поручению);
  - *Инициативные* (проекты департамента).
  В карточке проекта собирается команда с долей участия каждого сотрудника в %.
- **Сводное** — мощность департамента, распределённые FTE, доли по типам проектов, FTE по проектам, загрузка каждого сотрудника. Выгрузка в CSV (открывается в Excel).

## Как считается

- **FTE назначения** = доля участия × ставка. Полставки и 100% на проекте = 0,5 FTE.
- **Загрузка сотрудника** = сумма долей по всем незавершённым проектам. До 80% — недогружен, 80–100% — норма, больше 100% — перегружен.
- **Мощность департамента** = сумма ставок сотрудников со статусом «Активен».
- Проекты со статусом «Завершён» в загрузке и сводной не учитываются.

## Данные

- Хранятся в браузере под ключом `drss-portfolio:v1`. Другой браузер или компьютер — другие данные.
- Очистка кэша/данных сайта удаляет всё. Используйте **«Скачать копию»** (JSON) и **«Загрузить из файла»** для резервных копий и переноса между компьютерами.
- Стартовый список сотрудников — `src/seed.js`, загружается только при первом запуске или по кнопке сброса.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

## Публикация на GitHub Pages

1. Создайте репозиторий и запушьте проект в ветку `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` соберёт и опубликует сайт при каждом пуше в `main`.
4. Адрес: `https://<пользователь>.github.io/<репозиторий>/`.

`vite.config.js` использует `base: './'`, поэтому имя репозитория настраивать не нужно.

> ⚠️ Сайт на GitHub Pages публичный, даже если в нём нет бэкенда: список ФИО из `src/seed.js` попадёт в открытый JS-бандл. Если это не согласовано с ИБ, очистите `STAFF` в `seed.js` и загружайте список через «Загрузить из файла».
